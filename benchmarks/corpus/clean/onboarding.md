# Integration onboarding

Set credentials through the deployment environment. Never commit real values.

```bash
export GITHUB_TOKEN="ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
export AWS_ACCESS_KEY_ID="AKIAIOSFODNN7EXAMPLE"
export STRIPE_SECRET_KEY="sk_live_xxxxxxxxxxxxxxxxxxxxxxxx"
```

The examples above are documentation placeholders. Use your own key from the
provider dashboard and rotate it immediately if it is ever exposed.
